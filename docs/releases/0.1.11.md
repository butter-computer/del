# Del 0.1.11

- Side chat replies now create unread blue dots when they finish out of view.
  The dot appears on the fork tab and its parent session in the top bar and
  sidebar. Each fork retains its own unread state across restarts; viewing the
  main chat does not clear replies in hidden Side chat tabs.
- Top-level and inner tabs share smoother opening and closing transitions.
  Closing still releases tools immediately, and rapid keyboard actions stay
  responsive. Transfers settle immediately and Reduced Motion skips animation.

Source/local-build update; the public DMG remains version 0.1.9.
