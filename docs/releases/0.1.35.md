# Del 0.1.35 — session controls

This change is based on `main` at `5da20f3`, in an isolated worktree. It does not
merge or replace ongoing work on other Del branches.

- Hide session ages while their activity spinner is visible.
- Give the right sidebar a 360-logical-pixel minimum and keep Side chat provider
  and model controls on one row.
- Deliver explicit Steer actions during peer waits between native turns, while
  retaining peer obligations and later queued messages. Show rejected steering
  as a retryable queue error.
- Apply Del’s ordinary provider permission policy before spawning agent-created
  chats, including parents carrying legacy Ask settings.
- Create an independent side-chat tab on every new Side chat action, using the
  latest main conversation context. Preserve each chat’s storage and lifecycle.

See the [validation record](0.1.35-validation.md). Testing uses a separately named
Del instance with isolated mock data. No public release or DMG is published.
