# Del 0.1.20

The main area now stays on the selected agent, with tools collected in the right sidebar.

- Removed the main chat’s inner tab bar and cross-zone tab dragging. Existing main-area tools migrate to their session’s sidebar with their saved state.
- New sessions start with one **New tab** chooser, without preopened Files, Changes, Terminal, or Browser tabs.
- New-tab and tool shortcuts always open on the right, revealing the sidebar when needed. Command-W closes its active tab; Command-Shift-W closes the top-level session.
- Command-Left/Right switch top session tabs. Command-Up/Down follow visible left-sidebar sessions in displayed order, skipping collapsed groups. Navigation works with the composer focused and retains focus after session restoration.
- Sidebar tabs retain independent content, horizontal reordering, overflow fades, and persistence. Closing the last tab restores the chooser.
- Settings → Keybinds and the README describe the updated shortcuts.

This installer also includes the changes shipped in source since 0.1.13: composer and branch pickers, session-scoped browser previews, peer session creation and delegation, completed-work summaries, independent browser tabs, and file-tree and status-indicator refinements. See the earlier release notes for details.

The Apple Silicon release includes the DMG, its SHA-256 checksum, and the updater manifest. It is ad-hoc signed and not notarized, as described in the README.

This build uses the supported runtime Metal shader compilation path because the packaging machine has Command Line Tools without the standalone Metal compiler. Shaders compile from embedded source on first use.

See the [validation record](https://github.com/butter-computer/del/blob/v0.1.20/docs/releases/0.1.20-validation.md).
