# Del 0.1.17

- Fixed floating browser previews remaining on loading placeholders while the
  actual browser tab showed a fully rendered page, including YouTube.
- Preview sampling now lets the existing page render invisibly without exposing
  native controls, intercepting clicks, or showing background page dialogs.
  Rendering pauses again after sampling stops and cannot hide a reopened pane.
- Closing the sidebar preserves the browser viewport for the thumbnail instead
  of squeezing it down with the sidebar's closing animation.
- Retains the session-scoped, draggable previews, rounded page image, blurred
  close control, and suppression while a Browser pane is open.
- Adds native regression coverage for frame-driven rendering, thumbnail pixels,
  input isolation, rendering expiry, and reopening the same page.

This updates source and the local build. No new GitHub installer is published
with this commit.
