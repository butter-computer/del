# 0.1.36 validation

- Workspace tests: **844 passed, 0 failed, 48 ignored** (`cargo test --locked --workspace`). The ignored native-provider and platform tests were not rerun for this UI/history update.
- Clippy: `cargo clippy --locked --workspace --all-targets -- -D warnings` passed.
- Formatting: `cargo fmt --all -- --check` passed.
- Desktop build: `cargo build --locked -p del-app` passed.

Regression tests first reproduced blank peer previews, misplaced restored exchanges,
and steered messages inside work disclosures. They now cover empty/updated messages,
attachment-only navigation, restore idempotence, old snapshots with misplaced rows,
spawn receipts, failed-delivery recovery, exact legacy continuation filtering, and
long Claude receipt output remaining valid JSON. Existing GPUI branch-menu keyboard,
wheel, and bounds tests also pass.

A private copy of the reported Claude conversation was replayed through the native
history reader and SessionManager with a mock backend (no provider prompts).
All 15 exchanges in its current native conversation branch were restored in place,
with zero trailing receipts or internal continuation prompts. All 20 durable mailbox
receipts were preserved; five belonged to abandoned native retry branches and were
not manufactured into new transcript rows. Original application data was untouched.

A signed isolated 0.1.36 preview launched successfully. Manual menu interaction was
limited by desktop automation reporting `noWindowsAvailable`; the normal running
Del instance was left untouched. The preview was closed after inspection.
