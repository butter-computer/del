# 0.1.40 source update

The Side chat launcher reveals two equal halves on hover or keyboard focus.
The darker right half fades in smoothly over 240 ms with a history icon and opens
Side history. Loading uses shimmer placeholders without loading text; Reduce
Motion keeps the placeholders static and reveals the button immediately. The shortcut remains
**Option-Shift-Command-S**.

History is now a closable tab in the right sidebar, scoped to the selected main
conversation. Opening it again selects the same tab. Each entry shows its provider,
first prompt, and time since its latest prompt, sorted newest first. Opening an
entry restores its chat or selects its existing tab.

Prompt timestamps persist independently of snapshot saves, so reopening, draft
edits, and assistant responses do not promote old chats. Older snapshots without
that timestamp use their saved time and label it accordingly. Empty chats without
a sent prompt are omitted.

Validation: 26 Side chat tests passed, followed by the history regression tests
for tab reuse, restore/close, recency sorting, and avoiding repeated reads during
sidebar updates. Clippy passed with warnings denied. In an isolated mock app,
verified the split launcher and icon, opening/reusing the History tab, restoring
a chat, moving it to the top after a new prompt, and shimmer rows during a delayed
read followed by the completed list.
