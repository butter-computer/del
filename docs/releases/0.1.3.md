# Del 0.1.3

Fix automatic update discovery failing when GitHub's shared unauthenticated API
quota is exhausted. Del now reads `latest.json` from the release assets rather
than the GitHub API. Opening sessions, switching tabs, and returning to the app
check for updates with a 60-second cooldown; manual checking remains available.

Release packaging now produces the DMG, SHA-256 sidecar, and `latest.json`.
Publish all three assets together. Existing checksum, signature, version, bundle
identity, installer-lock, and rollback protections remain in place.

Apple Silicon, macOS 11 or later. Ad-hoc signed, not notarized. Users of older
builds affected by the GitHub API quota can download `Del-0.1.3-arm64.dmg` from
this release and replace Del.app in Applications, or retry after the quota resets.
