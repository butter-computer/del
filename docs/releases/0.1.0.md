## Del 0.1.0

The first public release of Del, a native desktop workspace for coding agents.

### Included
- Codex, Claude Code, and OpenCode conversations and terminal sessions, with multiple provider accounts.
- Project grouping, pinned and archived sessions, inline renaming, and independent conversation tabs.
- Branch selection and optional isolated Git worktrees.
- Queued follow-ups, steering, and interruption controls.
- Editable files with persistent drafts and conflict-aware saving, plus automatically refreshed Git diffs.
- Multiple workspace terminal tabs and an integrated browser with tabs.
- Native Apple voice dictation.

### Requirements
- Apple Silicon Mac (arm64).
- macOS 11.0 or later.
- Install and authenticate the provider CLI you want to use. Provider accounts, subscriptions, and model access are separate from Del.

### Install
Download **Del-0.1.0-arm64.dmg**, open it, and drag **Del.app** into **Applications**.

Like Alpha, this release is **ad-hoc signed and not notarized**. On first launch, macOS may require right-clicking Del.app → Open, or allowing it under System Settings → Privacy & Security. Microphone, speech recognition, and folder access are requested by macOS when needed.

The release has its own app identity (`computer.butter.del`). Switching from a development build may require granting permissions again.

### Verify the download
Download the matching `.sha256` file alongside the DMG, then run:

```sh
shasum -a 256 -c Del-0.1.0-arm64.dmg.sha256
```
