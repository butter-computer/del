# 0.1.56 source update

Fixes Side chat message wrapping and duplicate entries in the Processes menu.

- Short Side chat prompts such as “is that so” keep their natural width instead
  of wrapping one character per line. Longer messages, unbroken strings and
  explicit line breaks stay within the panel. Main-chat cards retain their
  full-width layout.
- **This session** and **Other sessions** show separate process lists. A command
  appears only once; empty drafts still show **All sessions**. Existing process
  ownership, live refresh and Stop controls are preserved.

The workspace packages, lockfile and macOS bundle metadata are version 0.1.56.
This is a source update; the latest downloadable installer remains 0.1.55.

See the [validation record](0.1.56-validation.md).
