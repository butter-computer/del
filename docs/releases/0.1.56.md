# Del 0.1.56

Fixes Side chat message wrapping and duplicate entries in the Processes menu.

- Short Side chat prompts such as “is that so” keep their natural width instead
  of wrapping one character per line. Longer messages, unbroken strings and
  explicit line breaks stay within the panel. Main-chat cards retain their
  full-width layout.
- **This session** and **Other sessions** show separate process lists. Each command
  appears once. Empty drafts show **All sessions**. Existing process
  ownership, live refresh and Stop controls are preserved.

Download **Del-0.1.56-arm64.dmg** for Apple Silicon Macs running macOS 11 or later.
The public app is ad-hoc signed and unnotarized. The release includes a SHA-256
checksum and the `latest.json` manifest for the in-app updater.

See the [validation record](https://github.com/butter-computer/del/blob/v0.1.56/docs/releases/0.1.56-validation.md).
