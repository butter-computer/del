# 0.1.36 source update

- Empty user/peer messages no longer create navigation ticks. Peer previews show their message text; attachment-only prompts retain a useful preview.
- On reopen, agent exchanges are restored beside their recorded send/reply/spawn tool calls. Incoming messages retain their native delivery positions. Settled receipts without a recoverable position remain in the mailbox instead of being appended after the final answer; outstanding deliveries retain recovery controls.
- Provider tool summaries retain valid receipt IDs when long messages are shortened, including Claude, Codex, and OpenCode.
- Exact older Del continuation prompts are hidden alongside the current version. User-authored text mentioning the same tags stays visible.
- Steered user messages remain outside collapsed “Worked for” sections.
- Branch menus show part of the next row immediately and use a taller 40 px fade. Memory menus show part of a fifth row with a 44 px fade. Fades disappear at the scroll end.
- Restore the original coffee cup SVG, retaining its animated steam and reduced-motion behavior.

The changes do not modify provider permissions, queue delivery, or saved messages.
