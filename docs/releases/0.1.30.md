# Del 0.1.30

- Let chat agents choose a starting branch, create a managed worktree, and select a model, reasoning effort, and service tier when spawning another chat. Preserve the caller's project, permissions, and same-provider account.
- Expose the live provider model catalog through `session_models`, without submitting an inference prompt.
- Add `configure_session` for idle spawned chats. Provider and model changes take effect together, preserve public history, and refresh the app's displayed settings.
- Add `close_session`, with optional archiving, for directly spawned chats. Preserve history and Git work, and pause unfinished peer work before closing.
- Restrict configuration and closing to the caller's direct children from the current Del launch. Keep ordinary project-wide peer messaging unchanged, and explicitly reject chat-only spawn options in Terminal mode.

- Add sidebar session hover cards with full titles, activity, project/checkouts, branch/worktree details, and provider logos. Preserve unread state and existing pin/archive actions.

These tools support council-style reviews using personal skills and the existing
peer mailbox. Del does not bundle a council skill or a separate review scheduler.

This is a source and local app version bump. It does not publish a new macOS download.
See the [validation record](0.1.30-validation.md).
