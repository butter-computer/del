# Del 0.1.25

Provider switching, a refreshed interface, and theme-aware animated backgrounds.
This public release includes the changes prepared in 0.1.24 as well as the
subsequent appearance and interaction improvements.

- Switch between Codex, Claude Code, and OpenCode within the same Del conversation.
  Preserve visible history, project, and tabs; each provider switch starts a fresh
  native session with separately attached public context and access to earlier
  conversation segments. Model and account controls follow the selected provider.
- Move between Chat and Terminal with `/chat` and `/terminal`, and open independent
  Side chats with the main conversation's context. Main and Side chat share queued
  message editing, steering, deletion, attachment previews, and drag reordering.
- Refine the sidebar, Space menus, session tabs, unread indicators, composer, and
  footer. Add curated themes, including tinted dark palettes and pitch-black Vercel.
- Choose theme-aware backgrounds including liquid, fluted glass, cloth curtains,
  rain, clouds, falling leaves, pudding, draggable Window Curtains, and seafloor
  caustics. Mouse interaction is optional and limited to the new-session page;
  reduced motion and inactive windows pause animation.
- Keep dialogs, sheets, and prompts from also manipulating the background. Isolate
  each asynchronous curtain pick so an old GPU completion cannot activate a newer
  drag. Preserve light and bright terminal fills to keep their text readable.
- Make Command-W follow the active zone: close the top session from the main chat,
  or the active tool tab from the right sidebar. Clicking either tab strip selects
  its zone, and Command-L returns closing behavior to the main chat. A hidden
  sidebar cannot intercept Command-W; an empty sidebar cannot close the session.
  Command-Shift-W remains an explicit close for the right-sidebar tool tab.
- Harden session journals, history restoration, provider handoffs, Space pins,
  terminal input, and recovery behavior from the earlier source update.

## Download

Install **Del-0.1.25-arm64.dmg** on an Apple Silicon Mac running macOS 11 or later.
The release includes a SHA-256 checksum and `latest.json` for the in-app updater.
The public app uses `computer.butter.del`, is ad-hoc signed, and is not notarized.
Local development builds retain their separate signing identity.

See the [validation record](0.1.25-validation.md) and the
[0.1.24 notes](0.1.24.md) for more detail on provider switching and chat queues.
