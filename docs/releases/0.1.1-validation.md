# Del 0.1.1 updater validation

Validated on Apple Silicon macOS on 2026-10-27. Release code: `3706fc1`.
The follow-up validation commit adds tests and this record only; it does not
change the released application behavior.

## Live upgrade

1. Built and installed a public-identity 0.1.0 bundle containing the updater.
   Startup check showed “Del is up to date”; the UI showed v0.1.0.
2. Kept that process running while pushing main/tag v0.1.1 and publishing the
   signed DMG plus SHA-256 sidecar from a complete draft release.
3. Clicked the manual update check in the running older app. It detected 0.1.1
   without restarting. This deliberately bypassed the 15-minute automatic cache.
4. Used the app's own download control. Observed Downloading, Preparing update,
   and Restart to update. The installed bundle remained 0.1.0 during staging.
5. Opened the confirmation and selected Later. The old process and staged
   download remained available.
6. Held `/Applications/.del-install.lock` with Python's `fcntl.flock` and
   attempted Restart now. The original process/version survived and the staged
   download remained available, confirming interoperability with the existing
   macOS installer lock.
7. Released the lock and retried Restart now. The app installed 0.1.1 and
   relaunched itself with a new PID. The installed signature passed
   `codesign --verify --deep --strict`.
8. Verified v0.1.1 in the UI and plist, “Del is up to date” after the automatic
   startup check, and the existing session list. Created/switched/closed empty
   test tabs and left the upgraded app running.

An accessibility automation click initially failed to open the confirmation.
A normal pointer click and the automated mouse-event regression test both opened
it successfully. The release was temporarily returned to draft during that
investigation and restored after verification; no production fix was needed.

## Automated coverage

- Full workspace suite: 412 passed, 0 failed, 36 intentionally ignored tests.
- Final app suite after the additional interaction test: 210 passed, 0 failed,
  9 intentionally ignored tests.
- Explicit public-release integration test: passed against the published 0.1.1
  DMG, including actual download, mount, copy, checksum and code-signature checks.
  It additionally rejects wrong versions, altered bundle identity, a changed
  destination installation, identical-version reinstall, and a tampered binary.
- Deterministic tests cover current/older releases, drafts/prereleases, invalid
  versions, missing/empty/oversized/untrusted assets, checksum/filename mismatch,
  failed replacement rollback, throttled/concurrent checks, simulated network
  errors, disconnected workers, external-command timeout/failure, installer-lock
  retry retention, every updater render state, and pointer-click confirmation.
- Existing macOS installer regression: passed (live bundle identity preserved,
  retired bundles cleaned after exit).
- Existing macOS signing regression: passed (identity retained, other keys
  rejected, incomplete identity fails closed).

Automatic startup was exercised live. Session/tab/focus checks use the same
throttled path; the live release detection used the explicit manual check rather
than waiting for the 15-minute cache to expire. Physical disk exhaustion,
Gatekeeper/translocation, and interruption by OS shutdown were not fault-injected.
The public release remains ad-hoc signed, not notarized.
