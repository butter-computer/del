Based on `origin/main` at `5da20f3`, in the independent
`codex/session-controls-fixes` worktree, on 2026-11-04.

## Reproductions and regression checks

The original code failed three targeted tests before the behavior fixes:

- `explicit_steer_reaches_idle_peer_wait_without_releasing_followups` returned
  `no turn in flight to steer` while a peer task blocked normal queued messages.
- `app_spawn_applies_normal_permissions_before_child_launch` observed `Ask`
  rather than `FullAuto` in the spawned Claude configuration.
- `new_side_chats_are_independent_and_capture_latest_parent` observed identical
  native session IDs after two new-side-chat actions.

After the fixes:

- `cargo test --locked -p del-app -p del-agent -p del-claude -p del-codex`:
  **609 passed, 0 failed, 36 ignored** across unit, integration and doc tests.
- GPUI tests click the actual Steer queue control while waiting on peers for
  Codex, Claude and OpenCode, then verify delivery and retention of later queued
  input and peer obligations.
- A GPUI layout assertion checks Claude and Opus 5.5 High occupy one row at the
  360-logical-pixel sidebar minimum and leave space for the Send button.
- Side-chat tests verify separate session and storage IDs, a newer main-chat
  marker only in the second fork, persisted tab identities/order, and closing one
  fork without closing the other. Existing transfer, unread, activity, queue,
  provider-switching and cleanup coverage also passes.
- Permission coverage includes a legacy Ask parent spawning Claude, temporary
  side-chat parents, ACP preservation, and the Claude adapter emitting both
  `--dangerously-skip-permissions` and `--permission-mode bypassPermissions` for
  new and resumed full-access chats.
- `cargo clippy --locked -p del-app -p del-agent -p del-claude -p del-codex --all-targets -- -D warnings`: passed.
- `cargo fmt --all -- --check` and `git diff --check`: passed.

The ignored checks require live providers, authentication or machine-specific
facilities. The initial regression pass used mock providers. The live acceptance pass below used authorized real inference in disposable test chats.

## Family cost regression coverage

- Independent sibling ledgers and repeated provider visits add together; legacy
  coverage floors and estimates reconcile inside each chat before aggregation.
- Duplicate/stale cumulative events cannot inflate or reduce captured usage.
- Side costs persist through serialization, owner migration, and tab closure;
  the main context meter remains independent of side-chat context size.
- A GPUI observer test delivers side usage through the real SideChat-to-AppState
  path and verifies the main status total.
- The live probe exposed Codex native forks copying parent token totals. Native
  temporary forks now subtract a known source baseline. Active/unloaded sources
  and durable forks use the existing transcript fallback when a stable baseline
  cannot be guaranteed. Mapping tests cover replay and connection resets.

Previously captured estimates retain their recorded values; unavailable historical
provider telemetry cannot be reconstructed reliably. These are usage estimates,
not subscription bills.
