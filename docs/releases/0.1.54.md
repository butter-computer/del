# 0.1.54 source update

Fixes three regressions found while reviewing the 0.1.53 polish pass.

- Sending during an attachment import now captures the message, destination and
  Send/Steer choice. Switching main chats, changing a Side chat or hiding Del
  cannot lose or redirect the accepted send. Later edits and imports remain in
  the next draft. A terminal draft completing in the background keeps the
  currently selected tab and its keyboard focus.
- Permanent session deletion waits for the latest queued save before removing
  its imported attachments. Stale saves cannot recreate the deleted queue.
- Expanded tool details retain every input and output line. The view is capped
  at 260 logical pixels and scrolls internally, containing wheel gestures at
  its edges instead of moving the surrounding transcript.

Validation is covered by regression tests for deferred main and Side sends,
original draft targeting, background terminal selection, queue deletion racing
with saves, complete long tool output, and the bounded nested scroll area.

The app suite passes: 490 tests, with 12 opt-in provider tests ignored. App Clippy
passes with warnings denied, and formatting checks pass. Native interactive
verification was not run; Del is left closed as requested.
