# 0.1.49 source update

Click a recent commit to expand its indented changed-file list. Click a file to
expand its diff, with old/new line numbers and addition/deletion highlighting.
Both disclosure levels support keyboard activation. Commit titles expand without
a chevron or vertical guide; file rows retain their disclosure arrows. The hash
sits on the left while the author sits beside the date on the right. Clicking
the hash copies the full commit ID, with a hover copy icon that changes to the same temporary check used by chat responses.
Copying never toggles the commit. Reopening and background polls preserve expanded files and reuse loaded results. File lists and individual
diffs load on demand; failures can be retried by closing and reopening the row.

Reviews use the selected commit’s immutable tree, including root commits, merges
compared to their first parent, renames, deletions, binary files, and metadata
changes. Preview limits still apply to large commits and diffs. Switching projects
discards the old review state and ignores late results from that project.

Commit dates now show Today, recent hours (such as “4 hrs ago”), Yesterday, or an
ordinal date such as “5th Oct”. Dates use the local timezone; older years include
the year and hover reveals the full timestamp. Labels refresh while history is
visible.

The footer shows the project folder icon/name before branch and change details.
Hover shows the full active directory; clicking opens Files.

Each diff is capped at 320 logical pixels high and scrolls independently in both
directions. Only the vertical scrollbar is shown; horizontal scrolling remains
available for long lines. Scroll offsets survive ordinary rerenders.

Commit and file disclosures use reversible 160 ms opening / 120 ms closing
transitions, with immediate state changes under Reduced Motion.

Validation: `cargo test --offline -p del-app` passed 447 tests (444 unit and
3 integration); 14 environment-dependent tests remain ignored. Coverage includes
historical Git edge cases, friendly date boundaries, rendered expand/collapse
clicks, hash copying without expansion, polling preservation, bounded
scrolling on both axes, and containment of diagonal/edge wheel events.

Historical and working-file reviews use the virtualized code-diff viewer with
syntax highlighting, aligned gutters, consistent change backgrounds, and file-type
icons. Scrolling within a diff never propagates to the outer list, including
diagonal gestures and scrolling at an edge. Only the vertical scrollbar is shown.
