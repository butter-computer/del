# Del 0.1.55 validation

Validated on an Apple Silicon Mac on 2026-11-06.

## Automated checks

- `CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 cargo test --offline --locked --workspace`:
  **925 passed, 0 failed, 52 ignored** across unit, integration and documentation
  suites. Ignored tests are not included in the pass count.
- `CARGO_PROFILE_DEV_DEBUG=0 cargo clippy --offline --locked --workspace --all-targets -- -D warnings`:
  passed. Formatting, whitespace and locked offline workspace metadata checks passed.
- Local signing and installation regression scripts passed.
- Seven process tests cover shell/housekeeping filtering, ownership across shared
  and detached process trees, TCP listener ports, stale PID rejection, forced
  shutdown, and preserving another session's server.
- The opt-in real-provider process test was also run separately against Claude,
  Codex and OpenCode before the version-only bump. Each provider started two real
  isolated conversations with detached local servers. Both inherited distinct
  session markers, appeared under the right owners and ports, and stopping one
  preserved the other. All three runs passed; these are separate from the 925.
- Codex replay tests validate the dynamic ownership marker and verify that a native
  fork receives a different marker from its parent.

## Interaction checks

The native UI was tested in an isolated workspace in both dark and light modes.
With two real local servers, This session showed one and All sessions showed two.
Hover revealed the trailing close button. Stopping the selected server updated
both sections while the menu stayed open; its port closed while the other session's
port remained open. Switching sessions showed the surviving server. Stopping it
from All sessions left both lists at zero and both ports closed.

The final public DMG app was launched with isolated data and a mock backend. It
rendered version 0.1.55 and the Processes menu successfully, then exited through
Command-Q. The user's existing Del instance was also closed normally.
