# Del 0.1.5

- Review all changed files in a single list with independent expandable diffs, line numbers, and per-file added/removed line counts.
- Keep Changes closed when restoring or switching sessions. File diffs start collapsed and reset when reopening the pane; background refresh preserves your current expansions.
- Show the file count and total added/removed lines in the header, with brighter green and red diff backgrounds.

Update through the control above Settings, or download `Del-0.1.5-arm64.dmg`.
Apple Silicon, macOS 11 or later. Ad-hoc signed, not notarized. The release includes
a SHA-256 sidecar and `latest.json` for automatic update discovery.
