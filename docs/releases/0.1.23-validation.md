- Existing width tests cover minimum/maximum bounds and saved widths; reveal tests cover reversing from the current position and Reduce Motion.
- In the signed local app, verified that a single Space has no indicator row.
- Verified resize drags starting on both sides of the enlarged 16-point target.

- Continuous held-drag reversal is covered by the state-sequence test; the UI automation API only performs straight start-to-end drags, so a physical out-and-back mouse gesture is not claimed as manually tested.
