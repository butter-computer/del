## Drag regression coverage

The regression test first reproduced the bug: entering a destination changed the
held preview's horizontal position to the insertion slot rather than preserving
the pointer offset. The shared placement code now uses the destination only for
row alignment; horizontal position continues to follow the pointer.

GPUI interaction tests exercise transfers in both directions while the mouse
button remains held. They verify continuous preview movement, unchanged vertical
alignment, live insertion gaps and neighbor movement, source ownership until
release, preservation of drafts, and restoration in the destination zone.

The updated feature build launched locally before the release bump, with Keep Mac
awake confirmed on. The live desktop drag check could not be completed because
macOS automation returned `noWindowsAvailable`; the automated interaction checks
passed. Ignored live-provider/native integration tests were not rerun.

Public artifacts are ad-hoc signed and not notarized, matching the prior release.
Provider accounts, local session data, and development signing credentials are
not bundled.
