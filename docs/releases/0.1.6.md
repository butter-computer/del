# Del 0.1.6

- Harden session persistence, cancellation, provider restart recovery, and pending approval cleanup.
- Scope chat browser access to the calling chat or its active OpenCode workspace members, preserving background browser operations without changing the selected session.
- Improve terminal input, selection, process cleanup, file drafts, transcript rendering, and native browser/dictation lifecycle handling.
- Verify app updates using the SHA-256 sidecar, bundle identity, version, and code signature; install in the background and back off provider update checks while sessions are open.
- Restore clean workspace formatting and strict Clippy checks, and update live integration fixtures for UUID account profiles, the shared title prompt, and managed browser sessions.
- Keep Codex running while model discovery or another request is in flight, and reattach failed provider sessions automatically on the next send without reopening the chat.

This is a source version bump. The downloadable GitHub release remains 0.1.5 until
0.1.6 assets are published. See [validation](0.1.6-validation.md) for checks and
remaining environment-dependent limitations.

Apple Silicon, macOS 11 or later. Public DMGs are ad-hoc signed, not notarized;
local development bundles retain their persistent signing identity.
