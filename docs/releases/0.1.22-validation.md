# Del 0.1.22 validation

## Automated checks

- `cargo fmt --all --check`: passed.
- `git diff --check`: passed.
- `cargo test --locked -p del-app --quiet`: 312 passed, 0 failed, 11 ignored.
- `cargo clippy --locked -p del-app --all-targets -- -D warnings`: passed.
- `./scripts/bundle-macos.sh`: passed; signed local bundle installed and launched as 0.1.22.

## Regression coverage

- Space switching retains drafts, tab identities, project membership, independent pins, and background startup ownership.
- Global tabs retain selection, closed tabs do not reappear, and disabling the preference keeps Settings open. The Settings regression failed before the fix with Chat selected instead of Settings.
- Project moves merge duplicate tab references, preserve running terminals and tab identities, transfer ordering, retain pins from either collection (including legacy Default pins), and retain global tabs. Newly opened global tabs are assigned to the destination when scoped tabs are restored.
- Deleting a Space preserves its contents in the remaining collection and cannot remove the last Space. Saved state round-trips and invalid collection data recovers to Default.
- Native GPUI gesture tests check finger-distance translation, both incoming and outgoing panes, axis capture, short/cancelled gestures, edge resistance, and release settlement. The release-path regression reproduced the rendering-phase panic before its fix.
- Create/Rename dialog keyboard submission creates exactly one Space and preserves identity when renaming.

## Live UI checks

- Compact icon menus, red Delete Space, name-only heading, close-set dots, and borderless name dialog inspected in Del Local.
- Global session tabs tested on and off; Settings stays open. Its row has no card background.
- Plus shows the rotated orientation while the Space menu is open and returns on Escape. The transition is reversible and respects the shared Reduce Motion setting.
- Project menu shows Move to Space and the other existing Spaces in its submenu. Move/merge mutations were verified with isolated automated state tests rather than rearranging the user's project collections.
- Existing Spaces and tab decks restored after restarting the app; clicking between Spaces restores their content.
- The automation tool's synthetic scroll does not reproduce a complete physical two-finger gesture, so finger tracking and release timing are covered by native GPUI event tests rather than claimed as a physical trackpad check.
- Caffeine is enabled in the final local build.

## Distribution

Workspace packages, lockfile, and local bundle metadata are 0.1.22. This is a source update; the public downloadable installer remains 0.1.20.
