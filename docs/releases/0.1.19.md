# Del 0.1.19

Chat agents can create project peers, delegate work, and receive their replies
without requiring the user to coordinate each worker.

- `spawn_session` creates real chat peers with inherited project, permissions,
  and same-provider account/model settings. Initial tasks use the durable mailbox.
- Intermediate activity stays visible while work continues. After the final
  answer finishes, earlier updates, tools, and peer exchanges collapse into an
  expandable **Worked for…** section. Only the final answer has Copy.
- Work details open and close with a reversible animation and reduced-motion
  support. Elapsed time includes peer continuations, survives reopening, and can
  be recovered from older Codex/Claude transcripts when timestamps exist.
- Tool disclosure arrows follow their labels. The new-tab URL area no longer
  has a horizontal divider in either zone.

See [peer sessions](../peer-sessions.md) and the
[validation record](0.1.19-validation.md).

This is a source and local-build update. The public downloadable installer
remains 0.1.13; no new installer is published with this commit.
