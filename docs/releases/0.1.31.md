# Del 0.1.31

- Fix session previews disappearing over Archive/Pin and archived-session actions.
  Those child tooltips were taking ownership of the shared popup, preventing the
  row preview from returning until the pointer left the row.
- Show previews after 120 ms instead of the generic 500 ms tooltip delay. Moving
  between rows updates immediately, with a brief fade and slide that respects
  reduced motion and does not restart on redraw.
- Remove the provider/model line from session previews. Keep provider logos in
  sidebar rows and all project, checkout and branch/worktree details in the card.

This source/local-app update follows [0.1.30](0.1.30.md). It does not publish a
GitHub release or DMG. See the [validation record](0.1.31-validation.md).
