# Del 0.1.57

The Processes menu now identifies Node and Python tools by their launcher,
script or module when available. For example, a Node process running the Concord
MCP helper appears as `concord-mcp`. Ambiguous and inline invocations keep the
executable name. Process labels omit full paths and command lines.

Click a section heading to expand or collapse its rows. Each text-only heading
uses the same animation as transcript disclosures and respects Reduce Motion.
**Shared** holds processes without a known session owner, including shared
terminal commands and provider helpers. It starts collapsed each time the menu
opens. The other sections start expanded, and live refreshes preserve your choices.

Download **Del-0.1.57-arm64.dmg** for Apple Silicon Macs running macOS 11 or later.
The public app is ad-hoc signed and unnotarized. The release includes a SHA-256
checksum and the `latest.json` manifest for the in-app updater.
