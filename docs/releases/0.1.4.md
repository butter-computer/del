# Del 0.1.4

- Hide the updater row when Del is already up to date. Available updates, download progress, retry, and restart controls still appear when needed.
- Give the restart confirmation an opaque, theme-aware background so conversation text cannot show through it.

Update through the control above Settings, or download `Del-0.1.4-arm64.dmg`.
Apple Silicon, macOS 11 or later. Ad-hoc signed, not notarized. The release includes
a SHA-256 sidecar and `latest.json` for automatic update discovery.
