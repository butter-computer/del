# Del 0.1.56 validation

Validated on an Apple Silicon Mac on 2026-11-07.

- `cargo test --locked -p del-app --bin del`: **496 passed, 0 failed,
  13 ignored** after the version bump. Ignored tests were not run.
- The Side chat regression test exercises the scrolling transcript at 240 and
  350 logical pixels. It covers short prompts, longer prose, unbroken strings,
  and explicit line breaks, checking card and text bounds as well as wrapping.
  Before the fix, “is that so” produced a 253-pixel-tall transcript row;
  the one-line assertion failed. The fixed layout passes.
- `cargo fmt --all -- --check` and `git diff --check` passed.
- `cargo metadata --locked --offline --no-deps --format-version 1` passed.
  All nine workspace packages and the macOS bundle version are 0.1.56.

Validation uses GPUI's automated layout tests; no interactive native UI check
was performed. No installer was built or published for this source update.
The existing Metal command-line-toolchain warning and `block 0.1.6` future
compatibility notice remain non-failing.
