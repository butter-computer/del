# Del 0.1.7

- Add session tool tabs and a shared new-tab launcher for Files, Changes, Terminal, Browser, and Side chat. New blank tabs remain open until closed, and each Terminal tab owns a separate shell.
- Fork side chats from the main conversation with independent model/account settings. Restore their conversation, draft, and selections across app restarts.
- Move tool tabs between the main area and right sidebar without restarting their contents. Both rows use matching widths, backgrounds, icons, and small hover-close buttons. Horizontal dragging opens insertion gaps, keeps the plus button beside the remaining tabs, and uses a darker preview without haptics or magnetic effects.
- Route Command-T and Command-Shift-W to the active inner-tab zone; Command-W closes the top-level session. Add launcher shortcuts for Changes (Control-Shift-G), Terminal (Control-backtick), Files (Command-P), and Side chat (Option-Command-S).
- Refine the dark theme, overflow fades, and sidebar resize handles. Empty left-sidebar space no longer moves the window.
- Include the unreleased 0.1.6 provider recovery, persistence, browser, terminal, and updater fixes. Codex model discovery keeps its backend running; failed provider sessions reconnect on the next send.

Apple Silicon, macOS 11 or later. This release is **ad-hoc signed and not notarized**. It includes the DMG, SHA-256 sidecar, and `latest.json` update manifest. Local development bundles retain their separate signing identity.

See the [validation report](https://github.com/butter-computer/del/blob/v0.1.7/docs/releases/0.1.7-validation.md) for checks and test limitations.
