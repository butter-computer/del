# Del 0.1.28 validation

Validated on an Apple Silicon Mac on 2026-11-03.

## Workspace checks

- `CARGO_PROFILE_TEST_DEBUG=0 cargo test --locked --workspace`: **789 passed, 0 failed, 48 ignored**.
- `CARGO_PROFILE_DEV_DEBUG=0 cargo clippy --locked --workspace --all-targets -- -D warnings`: passed.
- `cargo fmt --all -- --check` and `git diff --check`: passed.
- `CARGO_PROFILE_DEV_DEBUG=0 ./scripts/bundle-macos.sh debug`: passed; bundle version 0.1.28 and strict code-signature verification passed.

## Native animation checks

- `scripts/test-curtain.c`: rail travel limits, immediate hook movement, hold geometry, hover response, and picking passed.
- `scripts/test-curtain-picking.m`: asynchronous readback ownership and cancellation, first-frame hover, fast grabbing, and repeated side-to-side dragging passed. The test reads back the actual GPU vertex and requires its distance from the constrained hand position to stay below 0.001 logical pixels.
- The same renderer test moves a real AppKit window between paint and GPU submission, verifies displacement and vertical direction, and checks that inactive/resume does not replay old movement.
- `scripts/test-cloth.m`: full prediction/relaxation/commit simulations passed for horizontal and vertical window movement at the final 25% strength, pinned rails, direct dragging, finite positions and velocities, independent panels, and gradual release.

During local interaction checks before the final strength reduction, temporary diagnostics
recorded 772 live window-movement samples reaching the renderer, with a median interval
of about 7 ms. Those diagnostics were removed. Window movement was reduced from full
strength to 35%, then to 25% following user feedback. Grabbed fabric remains direct.

## Provider switching

Replay coverage verifies Del's Codex child process receives the unload setting and
still waits for the native close notification. Earlier native checks of this same
backend change completed three Claude/Codex round trips, with and without another
Codex chat open, without sending model prompts. See the
[provider-switch observations](../chat-terminal.md#codex-01591-release-delay-regression-2026-11-03).
