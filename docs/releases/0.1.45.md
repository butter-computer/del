# 0.1.45 source update

Side chat composers now use the shared slash menu, including suggestions after
ordinary text, filtering, Up/Down navigation, Enter/Tab selection, and Escape.
Catalogs come from each Side chat’s provider, account, and working directory;
changing its settings invalidates the previous catalog and in-flight results.
`/chat` and `/terminal` are excluded. Other provider-advertised skills and commands
remain available.

Skill completion preserves surrounding text and exact provider identities.
Selecting `/goal` enters Side chat goal mode without submitting the draft; goal
mode and selected skills survive saving and queued-message editing. `/fast`,
`/fast on`, and `/fast off` change only the Side chat’s model settings. Unsupported
or locked Fast changes show an error and keep the draft. Main and Side menus only
accept navigation and selection keys from their own focused composer.

Validation: reproduced the missing Side chat menu with a failing GPUI test. The
nine Side chat tests and nine shared command-menu tests pass, including real
catalog routing through a separate account backend, mode-command exclusion,
keyboard selection without submission, goal/skill queue restoration, scoped Fast
settings, and catalog invalidation after an account switch.

The full app suite passes (436 tests; 14 environment-dependent tests ignored),
and the locked debug build succeeds. Installed and verified the signed local
macOS app: an inline Side chat slash opens the catalog, filtering finds `/adapt`,
and Tab inserts its skill token while preserving the preceding text without
sending a message.
