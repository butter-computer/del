# Del 0.1.21

Sidebar tools now share the top title bar with session tabs, leaving more room for their content.

- Moved sidebar tabs, their plus button, and file visibility controls into the title bar above the sidebar. Removed the extra tab row inside the panel.
- Sidebar content and its title-bar tabs reveal together, reverse smoothly during quick toggles, and respect reduced-motion settings.
- Added space before the plus buttons and a short, centered separator between session tabs and sidebar tools.
- Removed the horizontal line below the title bar and the divider beside sidebar content, preserving resize controls.
- Existing sidebar tools, shortcuts, and saved session state remain available.

This is a source update; the downloadable installer remains 0.1.20.
See the [validation record](0.1.21-validation.md).
