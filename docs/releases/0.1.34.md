# Del 0.1.34

- Starting a session on a different branch no longer fails just because the source
  checkout has local changes. Del automatically prepares a managed worktree from
  the selected branch’s latest locally available commit, preserving the original
  branch, staged changes, unstaged changes, and untracked files.
- Failed-start retries reuse that worktree even after the source checkout changes.
  Chat, Terminal, and agent-created chats use the same preparation path.
- Clean shared checkouts still switch branches normally. Choosing the current
  branch keeps the existing working directory. No automatic fetch, pull, stash,
  reset, or copying of uncommitted source changes is performed.

This source/local-app update follows [0.1.33](0.1.33.md). It does not publish a
GitHub release or DMG. See the [validation record](0.1.34-validation.md).
