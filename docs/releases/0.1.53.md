# 0.1.53 source update

A polish pass across motion, the chat loop, errors, copy and the visual system,
from a full UI/UX audit. Behavior agreed in earlier releases is unchanged.

## Motion
- The shared row highlight (sidebar, menus, file tree) fades in on first hover and
  out on leave instead of popping; moving between rows still slides.
- Model, branch and Memory usage popovers fade in with a short lift and fade out.
  Dialogs enter with a fade and short slide and fade out over 140 ms.
- Cmd-K stays anchored while typing, highlights one row, and runs the chosen
  action immediately. The slash menu fades in, eases its height, and shows one
  highlight for pointer and keyboard.
- Toasts enter in 200 ms (was 400 ms with a 96 px travel). Tooltips and scrollbars
  respond faster. Spinners turn linearly and in phase; shimmers share one clock.
- Tool details, Thought, diffs, goal details, queued rows, attachment chips and
  approval cards reveal instead of popping in. Finished work folds smoothly.
- The Command-key tab number hints wait for a 600 ms hold, so shortcuts no longer
  flash badges across the tab strip. The ⌘J panel reveals and maximizes smoothly.
- Terminals keep their size during panel animations and resize once when settled.

## Chat and composer
- A ↓ pill returns to the latest reply after scrolling up; automatic queue and peer
  deliveries no longer pull a reader back to the bottom.
- While a reply runs, a typed draft turns the button into Send (queues) rather than
  Stop; the placeholder reads "Queue a follow-up…".
- Sending is no longer blocked while history loads or attachments import; the
  message is held and delivered when ready.
- Queue and Side chat saves happen in the background, keeping Enter instant.
- Prompts, tool output, reasoning and approval details are selectable; prompts
  have a hover Copy. Diffs scroll horizontally and file names open in Del.
- Failed turns show Retry inline instead of a duplicate toast.

## States, errors and copy
- Toasts have a severity and specific titles; background housekeeping messages
  hide on their own and duplicates coalesce.
- Permanently deleting a session asks first everywhere. Archiving a working session
  says its reply was stopped, with Undo.
- Files explains unreadable and empty folders; Changes explains Git failures in
  plain sentences. Unsaved file edits ask Save / Don't save / Cancel on close.
- Disabled controls say why. Settings shows install hints for missing CLIs.
- Consistent wording: "session", "Could not", real plurals, 24-hour times, `~`
  paths, formatted numbers.

## App and visual system
- The window remembers its size and position. The menu bar gains About, Hide,
  Edit and Window menus. New sessions never default to `/`.
- Shared tokens (`crates/app/src/ui.rs`) replace fractional rem sizes, a dozen
  muted greys and per-list hover fills. Floating surfaces share one radius and
  shadow; focus rings are drawn inside controls. Light-mode colors were fixed in
  the terminal launcher and browser preview.

Validation: the workspace test suite and workspace Clippy with warnings denied
pass. The mock backend was run and checked visually: chat streaming, the queue
button, approval cards, Cmd-K, Settings and first launch. That pass found and fixed
regressions in user-message wrapping, approval card width, a launch-time
"Not installed" flash, and tabs restored at launch freezing part way open.
