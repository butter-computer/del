# Del 0.1.16

- Added composer shortcuts: ⌃M for model selection, ⌃⇧M for effort, ⌃⇧P for provider/account, and ⌃⇧B for the starting branch in a new-session draft. Shortcuts target the active chat pane, including Side chats moved between zones.
- Added shortcut badges to picker tooltips and updated Settings → Keybinds.
- Model search takes focus when the popup opens. Typing, arrow navigation, Return, and reopening work without clicking the search field. Fixed a Side chat crash when opening model or effort controls through shortcuts.
- Return in the effort popup confirms the current settings, closes the popup, and returns focus to the composer without sending its draft.
- Added padding inside model rows and replaced the Refresh label with a compact icon to give search more room.
- Side chat provider menus use the owning app’s live account identities and profiles instead of hard-coded system-account labels and stale profile snapshots.

This updates source and the local build. No new GitHub installer is published with this commit.
