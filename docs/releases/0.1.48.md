# 0.1.48 source update

The first session tab now aligns with the chat page at the left sidebar’s minimum
width, including reduced zoom. Navigation reserves only the space available after
macOS window controls, and its buttons compact horizontally when needed. Sidebar
resizing, collapse, and Back/Forward controls remain available.

Context, Limits, and Cost footer items stay hidden until their values are known.
Reported zero values still appear; unknown context capacity no longer creates a
“Context —” item.

A regression test covers minimum, default, and maximum sidebar widths across
70%, 100%, 140%, and 200% zoom, with macOS and other platform title-bar insets.

Validation: 443 app tests passed (14 environment-dependent tests ignored), and
the signed locked build succeeded. Visual verification confirmed tab/page
alignment at the minimum sidebar width and no Context/Cost placeholders in a
new chat. All old Del instances were closed before relaunching 0.1.48.
