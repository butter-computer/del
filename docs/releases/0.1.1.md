# Del 0.1.1

Del can now update itself from the control above Settings.

- Check for updates at startup, when switching sessions/tabs, and when returning to the app. Automatic checks are throttled to 15 minutes; click the control to check immediately.
- Download with percentage progress and verify the release checksum, app identity, version, and code signature before installation.
- Choose Restart now or Later. Saved sessions remain available; running agents and terminals stop on restart.
- Retry failed checks and downloads. Failed restarts retain the staged update. Installation uses a shared lock, refuses to overwrite a changed installation, and rolls back a failed replacement.
- Development bundles retain their separate signing identity and do not self-update.

Download `Del-0.1.1-arm64.dmg`, open it, and drag Del.app to Applications. Version 0.1.0 users need this first upgrade manually to receive the updater.

Apple Silicon, macOS 11 or later. This release is ad-hoc signed and **not notarized**. If macOS blocks the download, use System Settings → Privacy & Security → Open Anyway for Del after verifying that it came from this repository. Do not disable Gatekeeper globally. A `.sha256` sidecar is included.
