# 0.1.43 source update

Starting a session from a clean checkout no longer fails when the selected branch
is already checked out in another worktree. Del detects that branch ownership and
creates a managed checkout with its own `del/session-<UUID>` branch at the selected
branch’s latest locally available commit. Existing checkouts keep their branches,
index, and files. Del does not fetch or copy uncommitted source changes.

Failed-start retries reuse the prepared checkout, including its edits, even if
the selected branch becomes available later. Chat, Terminal, and agent-created
chats all use the same preparation path. A clean checkout still switches directly
to an available branch.

Validation: reproduced the exact Git “already used by worktree” error with a
regression test, then passed all 13 Git/worktree tests in the full app. The native
build and diff checks passed. The signed local app was installed and relaunched;
the original message successfully received a response on a new session branch
while both existing branches were preserved.
