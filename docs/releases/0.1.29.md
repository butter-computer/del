# Del 0.1.29

- Show the resolved automatic model and configured effort before opening the picker, in main chats and Side chats. Read Claude model-specific effort settings and Codex configured reasoning effort; show Auto effort when a provider advertises choices without a default.

- Cover new chats, existing chats, provider switches, and repeated pointer drags across Claude, Codex, and OpenCode.
