# Del 0.1.10

## Changes

- Side chats show a working spinner in their own tab in either pane. The parent
  session's top tab and sidebar entry stay busy while any of its chats are working.
  The original inner chat tab also shows the main conversation's working state.
- Sending a Side chat message keeps its parent top-level tab open instead of
  leaving it as a replaceable preview. Activity remains separate from the main
  conversation's controls and clears when the turn finishes or the chat closes.
- Files gives more space to the tree before a file is selected, placing the empty
  preview near the bottom. Manually resized splits retain their size.
- Terminals retain a black background and readable text in light appearance.
- A faint horizontal separator sits below the top tabs. The right tab strip has
  a short floating divider centered in the gutter, with space above and below;
  no divider runs beside the content or the left sidebar.

This version is a source and local-build update. The latest public DMG remains
[0.1.9](https://github.com/butter-computer/del/releases/tag/v0.1.9).
