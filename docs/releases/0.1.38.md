# 0.1.38 source update

Hover the Side chat launcher to reveal **/ Side history** inside the button. The
150 ms fade slides gently from the right; Reduce Motion reveals it immediately.
**Option-Shift-Command-S** opens the same history for the current main session.

History lists saved Side chats with their provider logos. Choosing one restores
its transcript and draft, or selects its existing tab. Creating a new Side chat
still forks the latest main conversation. Closing a Side chat stops its work but
retains its snapshot. Files already deleted by earlier versions are unavailable.

Validation: 25 targeted app tests passed, including parent scoping, legacy
snapshots, provider switches, and selecting existing tabs. In a separate mock
instance, verified launcher hover, shortcut, closing/reopening a Side chat and
history after app relaunch. This does not implement keeping active processes
running after app exit; that background-session work is separate.
