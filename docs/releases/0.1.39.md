# 0.1.39 source update

Normal Quit now hides Del and keeps the existing runtime alive by default. Main
chats, Side chats, queued work, and integrated terminal sessions continue running.
Opening Del returns to the same live workspace, including output produced while
hidden. Closing the window and the Dock’s Quit action use the same preference.

**Settings → Sessions → Keep sessions running after quitting Del** controls this
behavior. Turn it off to shut down sessions on Quit. **Quit Del Completely** in
the Del menu, or **Option-Command-Q**, always stops the runtime. App-update
restarts and macOS logout/shutdown also use the full shutdown path. Force Quit,
crashes, and reboot survival are not supported; no separate session daemon is
installed. Dictation stops when the window is hidden.

Validation: lifecycle policy and preference tests passed; native Apple-event
reason tests cover logout, shutdown, restart, and Quit All. Clippy passed with
warnings denied. In an isolated signed app with real providers, a Claude main
chat, Codex Side chat, and integrated terminal each finished a delayed command
after Command-Q. Their marker files and returned transcript/terminal output
confirmed completion. Disabling persistence made normal Quit stop Del and its
child processes; the off setting survived relaunch. Option-Command-Q exited
with persistence enabled.
