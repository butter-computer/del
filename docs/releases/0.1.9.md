# Del 0.1.9

- Command-W now closes the active inner tab in the last-used main or right-sidebar zone. Command-Shift-W closes the top-level session. Update Settings → Keybinds and the documentation to match; closing the original main-chat tab never falls through to closing its session.
- Match top-level tab and drag-preview heights to inner tabs using the same zoom-scaled dimensions.
- Remove the visible divider below the top bar and along both sidebars while preserving sidebar resizing.
- Simplify conversation search results: use the same provider and terminal icons as the left sidebar instead of Chat/Terminal text labels.
- Include the 0.1.8 improvements: a centered vertical new-tab launcher with lighter cards and URL fields, the main chat's provider/model controls in Side chat, and a grouped, read-only Settings → Keybinds page. Side-chat model and account settings remain independent of the parent conversation.

Apple Silicon, macOS 11 or later. This release is **ad-hoc signed and not notarized**. It includes the DMG, SHA-256 sidecar, and `latest.json` update manifest. Local development bundles retain their separate signing identity.

See the [validation report](https://github.com/butter-computer/del/blob/v0.1.9/docs/releases/0.1.9-validation.md) for checks and test limitations.
