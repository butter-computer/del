# 0.1.52 source update

Quit Del (Command-Q) and Dock Quit now save the workspace and shut down the app.
Previously the default background-session preference cancelled normal quitting
and only hid Del, which made Quit appear broken.

Del → Run in Background preserves the existing live-chat, Side chat, queued-work,
and terminal behavior explicitly. Closing the window still follows the saved
background preference; Settings now describes that window-close behavior. The
Option-Command-Q shortcut remains an alias for full Quit. Workspace persistence
and the existing graceful provider shutdown hooks remain unchanged.

Validation: the new quit regression failed against the previous behavior and
passes with the fix. All 447 app tests passed (12 existing tests ignored), including
window-close policy and preference persistence. Native macOS quit-reason tests
also passed.

The signed macOS build was installed and its signature verified. The final live
UI check was blocked by the locked Mac; process inspection confirmed Del was
closed after installation.
