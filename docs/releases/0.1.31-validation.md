# Del 0.1.31 validation

Validated on an Apple Silicon Mac on 2026-11-04, following `1616206` (0.1.30).

## Reproduction and regression

- Before the fix, `cargo test --locked -p del-app --bin del session_hover_tests`
  failed both new regressions: no card within 200 ms and no session preview when
  entering directly over Archive. Shortening the delay alone fixed only the first.
- Removing the competing action tooltips fixed the button-hover regression.
  Buttons retain their accessibility names and click behavior.
- All six session-preview regressions pass: prompt entry; hover over Archive/Pin;
  hover over Restore/Delete; immediate adjacent-row changes; unchanged selection
  and unread state with leave/press dismissal; and a reveal animation that reaches
  its final position and does not restart on redraw. Behavioral tests use reduced
  motion; the animation test explicitly enables motion.

## Application checks

- `cargo clippy --locked --workspace --all-targets -- -D warnings`: passed.

- `cargo test --locked -p del-app --bin del`: **405 passed, 0 failed, 12 ignored**.
- `cargo fmt --all -- --check`, explicit rustfmt check of the vendored tooltip
  file, and `git diff --check`: passed.
- `cargo metadata --locked --no-deps --format-version 1`: all nine workspace
  packages resolve to 0.1.31.
- The shared tooltip renderer is exercised through the app's real GPUI root and
  row controls. Cargo cannot run `gpui-component`'s own dev tests from this
  workspace because the vendored dependency is not a workspace member.

## Packaging

- `./scripts/bundle-macos.sh`: passed; signed bundle version 0.1.31.
- Strict deep signature verification passed for the installed `Del Local.app`.
  Its binary matches the signed build with SHA-256
