# Del 0.1.8

- Center new-tab launcher options in a compact vertical stack in both tab zones, with lighter card and URL-field backgrounds.
- Reuse the main chat's provider button and searchable model picker in Side chat, including effort, Fast mode, and reset controls. Keep account names in the submenu and settings changes scoped to the fork.
- Add a read-only Settings → Keybinds page with grouped app and contextual shortcuts, starting directly with the shortcut groups. Remapping is not available yet.
- Cover side-chat model changes with a regression check that verifies transcript and saved settings survive while the parent model stays unchanged.

This is a source and local app version bump. The published macOS download remains
[0.1.7](https://github.com/butter-computer/del/releases/tag/v0.1.7).
