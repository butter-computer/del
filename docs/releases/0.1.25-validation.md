# Del 0.1.25 validation

Validated on an Apple Silicon Mac on 2026-11-02.

## Automated checks

- `CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 cargo test --locked --workspace`:
  **758 passed, 0 failed, 46 ignored** across unit, integration, and documentation
  tests. Ignored tests were not included in the pass count.
- `CARGO_PROFILE_DEV_DEBUG=0 cargo clippy --locked --workspace --all-targets -- -D warnings`:
  passed. Formatting, whitespace checks, and locked offline metadata resolution passed.
- Local signing and installation regression scripts passed, including preservation
  of the signing identity while replacing a running app.
- All twelve native GPU backgrounds compiled at the macOS 11 Metal language level,
  rendered distinct animated frames, paused correctly, and used the supplied tint.
- Cloth solver, curtain rails, 373 rain impacts, and asynchronous curtain-picking
  checks passed against the native implementation.

## Interaction checks

- In the installed app, created an unsent disposable draft and a sidebar tab.
  Command-W from the sidebar URL field removed only that sidebar tab and preserved
  the draft. Clicking the main composer and pressing Command-W then closed the
  top-level draft and returned to the existing conversation. No prompt was sent.
- Verified that Settings opens and shows the updated shortcuts, and that the
  theme-tinted curtain background renders in the installed app.
- GPU regression checks deliberately block a replacement curtain pick while an
  older pick finishes. Separate buffers and readiness flags prevent the old
  completion from activating the replacement. Style changes and disabled mouse
  interaction cancel pending picks without late completion restoring them.
- Terminal contrast tests preserve white, warm light, gray, and bright colored
  fills while allowing compatible dark TUI backgrounds to become transparent.

for the earlier source update; their results are recorded in

for this release. Ignored provider/network/UI tests remain opt-in.
