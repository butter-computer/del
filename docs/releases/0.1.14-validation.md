Validated on Apple Silicon macOS on 2026-10-29.

- Full workspace tests: 521 passed, 0 failed, 41 ignored.
- Strict workspace Clippy: all targets passed with `-D warnings`.
- Formatting and whitespace checks passed.
- Local release bundle built and signed with the existing development identity.
- The branch-picker interaction test uses 101 names, including a long non-Latin
  name. It checks the height/width bounds, wheel scrolling, Page Down and arrow
  navigation, keeping the highlighted row in view, case-insensitive typed search,
  Return selection, Escape dismissal, and empty-result safety.
- Existing drag tests cover both tab rows and cross-zone transfers. Tab haptics
  reuse the sidebar's native level-change feedback and fire on target changes.

Live verification now passes: the picker opens below its button with an icon-free
search field, stays within the window, scrolls without a scrollbar, and removes its
bottom fade at the end of the list. Page Down/arrow navigation, case-insensitive
search, empty-result safety, Return selection, and Escape dismissal were checked
in the rebuilt app. The focused branch interaction test passed again after the
placement and width adjustments.

`TISCopyCurrentKeyboardLayoutInputSource` / `CFPasteboardCreate`, before UI setup.
No new Del crash report was found. The service wait resolved, and the rebuilt app
subsequently restarted normally. Caffeine is enabled in the running local app.

build to 0.1.14 without publishing another GitHub installer.
