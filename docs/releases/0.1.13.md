# Del 0.1.13

- Tabs remain attached to the pointer when dragged between the main chat area and right sidebar. Continue dragging to rearrange them in the destination row, then release to place them.
- Neighboring tabs make room while dragging; the original horizontal grab offset and tab width stay consistent across zones.
- Preserves horizontal-only dragging, the darker dragged-tab preview, and live tab contents including terminal sessions and drafts.

Apple Silicon, macOS 11 or later. This release is **ad-hoc signed and not notarized**, matching the previous public release. It includes the DMG, SHA-256 sidecar, and `latest.json` updater manifest. Local development builds retain their separate signing identity.

See the [validation report](https://github.com/butter-computer/del/blob/v0.1.13/docs/releases/0.1.13-validation.md).
