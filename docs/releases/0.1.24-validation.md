## Core hardening merge review — 2026-11-02

Reviewed `claude/harden-core` (`26dbf6f`) together with main's terminal-history
cleanup (`ec8785f`). The documentation conflict retained both validation records;
provider adapters and their cleanup/turn-lifecycle changes merged together.

Two issues were corrected before merging:

- Repeated whole-string paste-marker removal took 18 seconds for a 192 KB nested
  input in an optimized reproduction. Replaced it with a single-pass suffix

  an explicitly removed pin. The regression failed with `[false, true, true]`
  instead of `[true, false, true]`. Resolve legacy state before changing the first
  Space, then merge effective pin maps. Both cases now pass.
