# Del 0.1.24 validation

Validated on an Apple Silicon Mac on 2026-11-02.

## Automated checks

- The workspace suite passed during implementation: **608 passed, 0 failed,
  45 ignored**, including unit, integration, and documentation tests.
- After the final queue layout adjustment, the three provider-specific Side chat
  UI scenarios passed again. These use mock Codex, Claude, and OpenCode backends
  and exercise Edit/Delete clicks, draft and attachment preservation, blank
  Cmd-Return, Enter queueing during an active turn, steering a draft, ordered
  follow-up delivery, and isolation from the parent chat.
- Each scenario also checks that Steer, Delete, and Edit remain within the
  sidebar’s minimum 220 px width without overlapping.
- Workspace Clippy passed with `-D warnings`; app/all-target Clippy passed again
  after the final UI changes. Formatting and whitespace checks passed.
- Workspace package metadata, Cargo.lock, and the local app bundle version are
  aligned at **0.1.24**. Locked offline Cargo metadata resolution passed.

## Native provider checks

The provider-switch integration run passed all six cross-provider switch
directions using the installed, authenticated CLIs, with nonempty native model
catalogs. The chat/terminal/chat integration check passed separately for Codex,
Claude, and OpenCode, including repeated handoffs, preserved history/context,
Side chats on the other providers, and keeping a sibling Codex chat live.
These runs preceded the final queue-only UI changes.

## Native UI checks

- Compared main and Side chat queue rows in an isolated mock-provider profile.
- Verified light and dark surfaces, attachment previews, four visible rows with
  scrolling, long-message truncation, and visible actions at minimum sidebar width.
- Edited a queued Side chat message with an existing draft. Its previous draft
  remained in the saved queue; the main queue was untouched.
- Checked the shorter, more closely spaced conversation-navigation markers.
- Rebuilt and signed the local debug app with the existing development identity.
  The final app is retained outside the Rust build cache so cleaning `target`
  does not remove the installed application.

## Distribution scope

This update prepares source and a signed local development app. It does not
create or publish a 0.1.24 DMG, update manifest, Git tag, or GitHub release.
The public download remains 0.1.23. Ignored tests are not covered by the workspace
pass count; the separately executed native checks are listed above.

Existing non-failing build notices remain: runtime Metal shader compilation when
`xcrun metal` is unavailable, and future Rust compatibility for `block 0.1.6`.
