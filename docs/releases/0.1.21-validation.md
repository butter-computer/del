# Del 0.1.21 validation

The implementation was rebuilt, installed, and checked in Del Local before the version bump:

- Sidebar tools appear in the top title bar, with content immediately below and no duplicate tab row.
- Sidebar closing and reopening, Command-T, Command-W, the plus button, and opening Files were checked locally.
