# Del 0.1.26

- Replace the footer’s provider/model labels with branch and changed-file counts, colored line additions/deletions, context usage, account allowance, cost, and running processes. Keep the Chat/Terminal switch available.
- Show active-model context as percent used when capacity is known, and identify account allowances by email. Remove refresh timestamps and the provider/account action from footer popovers.
- Show the active provider’s captured conversation cost in the footer. Hover or click for Claude, OpenCode, and OpenAI/Codex totals across repeated provider switches. Persist costs across restarts and reconcile reported costs with token estimates without counting replayed updates twice.
- List current-session commands and servers with PIDs and listening ports, with a separate All sessions section. New drafts show all sessions. Hide background connections, shells, and helpers; empty sections say “0 running”.
- Fade overflowing composer text above the provider controls while preserving editing and scrolling.

Costs marked `(est)` use known standard model rates, not subscription billing.
Older activity, Terminal usage, unknown models, and model/tier changes can limit
coverage. Commands from shared provider servers with unverifiable ownership
appear only under All sessions.

This is a source and local app version bump. The published macOS download remains
[0.1.25](https://github.com/butter-computer/del/releases/tag/v0.1.25).
See the [validation record](0.1.26-validation.md).
