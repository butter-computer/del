# Del 0.1.2

This maintenance release adds regression coverage for automatic update detection
when opening sessions and switching tabs. Both actions share the updater's
selection observer. Checks remain throttled to once every 15 minutes; the manual
control can check immediately.

The tests exercise real session creation and tab selection, verify cache expiry
and release detection without startup/window-focus/manual checks, and confirm
that the update offer survives subsequent navigation.

Download `Del-0.1.2-arm64.dmg`, or use the update control above Settings in Del
0.1.1. Apple Silicon, macOS 11 or later. This release is ad-hoc signed and not
notarized; a SHA-256 sidecar is included. The existing macOS Gatekeeper approval
instructions in the README still apply to manually downloaded copies.
