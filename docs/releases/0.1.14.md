# Del 0.1.14

- Search local and remote starting branches in a compact picker. The search field is focused on open, and filtering ignores case.
- Branch results are capped at eight visible rows and fit the available window space. Scroll with the wheel or trackpad, without a visible scrollbar. A gradual bottom fade indicates more results below.
- Use arrow keys or Page Up/Page Down to navigate branches, Return to choose, and Escape to dismiss. The keyboard selection stays visible; no hint footer is shown. Settings → Keybinds lists these controls.
- Top-level and inner tabs now use the same native haptic feedback as sidebar session reordering, including cross-zone insertion changes. Movement within the same slot stays silent.

The versioned source and local build are updated; the latest published GitHub installer remains 0.1.13 until a separate release is published.
