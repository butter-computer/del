# Del 0.1.24

Switch between Codex, Claude Code, and OpenCode within one conversation, with
matching follow-up queues in main chat and Side chat.

- Keep the same Del chat, visible history, project, and tabs across provider switches.
  Each switch creates a fresh native session, including when switching back.
  A transcript row records the change; the provider, account, model, and effort
  controls follow the active provider.
- Attach carried-over public context separately from the first user prompt. Agents
  can read the original conversation and previous provider segments through
  `read_session`; private reasoning is excluded from transferred context.
- Use `/terminal` and `/chat` to hand the current native session between the chat
  view and provider CLI. Preserve context and merge terminal activity back into
  the transcript. Provider changes stay locked while Terminal owns the session.
- Open independent Side chats with the main conversation’s context, including
  while the main chat is in Terminal. Side chats have their own provider/account
  settings, searchable models, effort controls, and durable follow-up queues.
- Use the same Steer, Edit, Delete, drag-reordering, attachment previews, and
  four-row scrolling queue in both chat surfaces. Enter queues during a reply;
  Cmd-Return steers the draft or sends the first queued item from an empty input.
  Editing preserves the existing draft and attachments as another queued message.
  Queue controls fit the minimum sidebar width.
- Make conversation-navigation bars shorter and closer together, while retaining
  hover magnification and the single highlighted marker.
- Harden session journals, index recovery, delete/resume ordering, peer aliases,
  provider history, and terminal input handling. Preserve effective pins when
  deleting any Space, and keep nested terminal-paste marker filtering linear.
- Clean terminal control sequences and native command artifacts from restored
  history while retaining actual user text, Unicode, tool details, and literal
  code/XML examples.
- Include the updated Nabla app icon and the latest sidebar animation, project
  toggle, footer, and keep-awake fixes from main.
